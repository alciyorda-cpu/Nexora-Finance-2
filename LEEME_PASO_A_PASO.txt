NEXORA FINANCE - PROYECTO ANDROID

IMPORTANTE: Este ZIP contiene un proyecto Android real con una app WebView y un flujo de GitHub Actions para generar un APK de prueba (debug). No es el APK terminado.

PASOS DESDE ANDROID:
1. Descomprime este ZIP en el teléfono.
2. En GitHub abre tu repositorio privado Nexora-Finanzas.
3. Toca Add file > Upload files.
4. Selecciona TODOS los archivos y carpetas de este proyecto, incluidos .github y app. Si el selector no muestra archivos ocultos, crea/sube .github/workflows/build-apk.yml por separado usando el editor web de GitHub.
5. Mantén la estructura de carpetas. No subas el ZIP como único archivo.
6. En GitHub abre Actions. Si aparece una advertencia para habilitar workflows, actívalos.
7. Selecciona “Build NEXORA FINANCE APK” y toca Run workflow.
8. Cuando termine en verde, abre la ejecución y descarga el artefacto “NEXORA-FINANCE-APK”. Dentro estará app-debug.apk.
9. Descarga el APK y ábrelo. Android puede pedir permiso para instalar desde Chrome/Archivos.

QUÉ INCLUYE:
- Proyecto Android Gradle, aplicación WebView y workflow automático de compilación.
- Interfaz financiera inicial que guarda movimientos localmente en el dispositivo.

LIMITACIONES:
- Esta versión inicial no sincroniza datos entre teléfonos, no incluye cuentas con contraseñas de ambos usuarios ni auditoría resistente a manipulación.
- Los datos se guardan en el almacenamiento local de la aplicación. Exporta respaldos.
- APK debug para uso/prueba; no es una app bancaria certificada. No introduzcas credenciales bancarias ni información extremadamente sensible.
